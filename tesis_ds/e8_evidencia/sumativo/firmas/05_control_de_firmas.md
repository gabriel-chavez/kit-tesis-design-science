## 2. Incidencias

| Fecha | Incidencia | Decisión |
|:--|:--|:--|
| | | |

Casos posibles: un participante no autoriza; la observadora corrige el campo de ayuda; alguien pide aparecer con iniciales; falta una firma; el escaneo quedó ilegible.

## 3. Consecuencias por escenario

| Escenario | Efecto sobre la tesis |
|:--|:--|
| Todas las firmas y consentimientos | Los datos de P1 y P2 pasan a **verificados**; la aplicabilidad se reevalúa |
| Falta un consentimiento | Se excluye a ese participante; la aplicabilidad se declara con n = 1 |
| Falta la declaración de la observadora | Los datos siguen como **piloto no verificado** |
| La observadora corrige la ayuda a "no hubo" | Se rehace el conteo y se documenta la corrección |
| Alguien pide iniciales | Se corrigen las hojas antes de firmar y se rehace el escaneo |

## 4. Cierre

Cuando el registro esté completo:

1. Actualizar `08_evaluacion.md` §9.3 y §9.4.
2. Actualizar `00_estado.md` (preguntas abiertas y decisión).
3. Registrar los escaneos en `firmas/escaneos/`.
